# ChromaTextConverter

Converts Chroma ATE plain-text report files to WATS UUT reports.

## Input Format

Tab-separated plain-text report generated by the Chroma ATE test system.

Key header fields: Test Program Name, Serial No, System Time, Model Name, Elapsed Time, LOT Number, Inspector, Order Number, Customer, Test Result.

Test steps are separated by 80-character `=` lines. Each step may include a numeric limit line with min/measured/max values.

## Usage

```csharp
var args = new ChromaTextConverter().ConverterParameters;
args["operationTypeCode"] = "600";
var converter = new ChromaTextConverter(args);
```
